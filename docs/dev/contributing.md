# Contributing

The repository’s [CONTRIBUTING.md](https://github.com/geocoug/execsql/blob/main/CONTRIBUTING.md) is the maintained development setup and verification checklist. It covers environment setup, quality checks, tests and local database containers.

Use the [architecture guide](architecture.md) to locate a feature, the extension-development guides for registration requirements, and the [release process](releasing.md) for publishing and recovery. The [Python API](../api/index.md) is for applications embedding execsql; CLI internals are documented separately from the [user command reference](../reference/cli/index.md).
